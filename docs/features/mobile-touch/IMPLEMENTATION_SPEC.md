# YuDesk 手机屏幕交互实施规格

状态 ready。版本依据为 CrossDesk v1.7.7-20261124。来源为本目录 REQUIREMENTS.md（SHA-256 74dfcd07702a3ed214ce584d5745c6d048e0a3800dc71cd9d12027aafb082c6d）与 TECH_DESIGN.md（SHA-256 ad2b94f0580ae4ad574d8adc8cbec8a43028aedc7cc668b1de1ae0dd598e593c）。设计审查 yudesk-touch-design-r2 已批准。

| 编号 | 场景和必须可观察的结果 | 验证入口 |
|---|---|---|
| G1 | 华为新装默认相册触控；会话内及设置可切换，既有相对、绝对、物理鼠标和虚拟按键可用。 | 模式设置、会话工具、重启后回读 |
| G2 | 双指围绕中点缩放 1–10 倍，单指拖移（含长按后拖动）只改变本地可见范围；1 倍居中、边缘收敛。未发生移动的有效轻点才按显示器归一化坐标发送一次点击。双指同向滑动锁定为滚动，向起点定位后送滚轮。 | 用两块独立滚动区记录 Mac 点击和滚动；缩放和平移只动视野，留白/取消/多指尾巴不点击 |
| K1 | 可编辑控件点中后调起系统输入法；点击只读区域或按钮、查看手势、过期回包、手动关闭、切屏或断开均不误弹。支持宿主只处理本次已应用且同源的常规左键配对，确认 AX 命中与焦点同属可编辑目标。 | Android 状态及 Mac 判定测试，真实文本框、只读文字、按钮；中文输入一次，保留手动入口 |
| K2 | 有序鼠标流的可选顶层字段 ime_tap 为正整数，ime_display 为有效显示器索引，与两次按钮事件同送。响应由同一连接的控制流返回 type=yudesk_ime、id、display 和 editable 布尔。宿主缺少扩展仍执行原点击一次。 | 旧宿主兼容；失序、错显示器、断线重连、拒绝、超时、队列拥塞均不误弹 |
| D1 | Android 与 Mac 独立 YuDesk 安装、设置与运行身份；使用正常系统授权；官方升级、迁移及账户配置不影响该版本。Snug 可预建 1920×1080 电脑屏，Mac 实体主屏保留。 | 安装标识、构建验签、运行、同网段会话及选屏，历史工作树可恢复 |

AX 只识别类型和可编辑性，不读内容和标题。手机只对当前有效请求打开现有 RemoteKeyboard，每次触摸开始、模式/显示器或会话变化、手动关闭均使旧请求失效。窗口布局、认证、自建网络和编码沿用上游。个人应用数据留在原安装中，官方包与旧版项目均可供对照和回退。
