# YuDesk 相册触控与输入法设计

基线为 kunkundi/crossdesk 的 c3916910653a093588c8a85ca3b6f886720edd49。独立 Android applicationId 供并行安装，Java 命名空间保持 JNI 兼容。复用 RemoteViewport、RemoteMouseInput、RemoteKeyboard 与 SessionControls。原鼠标模式保留原事件路由。手指按下时相册路径仅记录坐标；单击在抬起时一次映射。拖动使用触摸阈值，双指以起点跨度或中点的累计位移锁定缩放/滚动，滚动沿用鼠标轮协议；新增、抬起或取消触点防止落单手指导致点击。切模式、失焦、切屏和断线清理本地状态。只读放大/平移不向远端发送输入。

## 已认证会话的输入反馈

官方宿主能运行普通相册手势。为准确区分只读文本与输入框，YuDesk Mac 宿主通过 macOS 辅助功能核对已接受点击的屏幕落点与当前焦点。沿用当前受权的 CrossDesk 会话、数据通道和已授予的 macOS 辅助功能权限。仅发回本次请求标识与可编辑判定，不读取或传输字段值、标签、窗口标题、选区、密码、可访问性树或文本。宿主拒绝未授权源、过期会话与无效坐标，只在交互时查询，失败时不弹。手机只处理当前会话、当前显示器及最新点击的及时响应，界面切换、手动关闭和下次触摸作废旧请求。上游宿主无此识别时退回手动键盘。既有协议、服务端、Snug 和视频编码链路保持兼容。

## 验证与回退

验证手势判定、边缘与留白、互斥、取消、IME 迟到和非编辑控件；通过实际 UI 验证显示器切换、模式选择、输入法弹出和可见的中文输入。额外区分 UIKit/第三方自绘控件未暴露可编辑角色的情况。代码、发布和应用配置仅针对 YuDesk；官方客户端保留供对照。旧版包含未提交文件和关联 worktree，在本地采用同卷完整移出与 worktree 路径修复。线上 RustDesk 服务、手机中已有应用和旧 GitHub 仓库保持独立。

### 输入关联与运行身份

Android 把单调递增请求号与当前显示器索引附在同一可靠鼠标流的常规左键点击上，旧宿主忽略扩展字段并照常执行一次点击。支持反馈的宿主只处理已授权同一连接、真实应用的配对左键落点；不提供按任意坐标查询的入口。用注入时相同的显示器实例和全局逻辑坐标（含负坐标及 Retina）对照 AX 命中控件、已获焦控件和前台应用，必要时限时重试；在延时工作前后复查源连接身份、显示代次和时效。拒绝早到、掉线、过期请求；无权限、AX 超时/只读/未知均安静降级。两指滚动仅在判定完成后先在有序鼠标流移至起点，再送滚轮，纯查看动作不发送移动。

定制 Mac 宿主作为独立 YuDesk 应用发行，使用独立 bundle ID、配置/缓存/日志及单实例命名，禁止旧 TCC 迁移和官方更新器覆盖。保持官方安装，按需切换运行，端口以宿主实际显示为准；首次授权通过 macOS 正常界面。Snug 预建非主屏扩展显示器，两个宿主都可捕获同一系统显示器，逐项检验扩展屏枚举和手动移窗，不依赖 Snug 识别 fork 身份或自动移窗。独立 Android 包不接收官方更新 APK。
