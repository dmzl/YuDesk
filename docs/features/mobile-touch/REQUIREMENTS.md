# YuDesk 移动端操作屏幕

本人及家人从华为 Android 连接 Mac，选中 Snug 的扩展显示器，查看 Codex、浏览器和终端。推荐先用 1920×1080 横向电脑屏，通过 Snug 菜单把工作窗口移入。实体显示器继续显示其他窗口。两块屏共享一个 macOS 用户的键鼠焦点。局域网可按 CrossDesk 的 IP 直连流程使用；外网沿用既有 CrossDesk 连接方式。

## 选屏与分辨率

华为在显示器列表选中「Snug 手机屏」或「YuDesk 工作屏」后，应看到所选屏自己的窗口。切换期间清除上一屏的画面。目标暂不可用时等待该屏恢复。画面设置保留固定分辨率，并提供「跟随电脑当前分辨率」。跟随时使用当前所选屏的系统尺寸，重连时也尊重电脑当时的设置。每块屏分别记忆选择。

## 相册触控

新安装的 YuDesk 默认使用相册触控，可在原设置及会话内切到相对鼠标或绝对鼠标，以后沿用已选模式。相册模式轻点落点发送一次左键点击，连续两次轻点允许 Mac 识别双击。对准两指中点缩放 1 至 10 倍。放大后单指（含长按后拖动）随手平移本地画面，整体可见时保持居中。缩回原比例恢复全图。双指同向上下滑动滚动手势开始处的远端内容，缩放和滚动一经判定直至离手只产生一种效果。平移、缩放和取消都不向 Mac 误发点击、光标移动或拖选。留白轻点无效，进入新屏幕后重置视图。物理鼠标与原有鼠标工具继续可用。

## 自动弹出键盘

用户点入可编辑文本框后自动打开 Android 当前系统输入法，可直接输入中文，手动键盘按钮继续可用。验证原生 Mac 输入框与浏览器可编辑控件，观察 Codex 自定义编辑器的实际可识别范围。按钮、只读文字、空白、滚动与缩放不会因本次手势弹键盘。不能确定是否可编辑时保留手动入口。自动弹出只对应当前会话、显示器和最近一次有效轻点，用户已关闭键盘时应尊重该操作。沿用现有输入法组合、提交和键盘避让。

## 安装与验收

Android 应用名 YuDesk，与官方 CrossDesk 并存，用户自行在新版输入设备或 IP。原服务器、凭据和其他应用数据均不复制到新应用。用公开测试内容观察华为屏幕与 Mac 的实际输入结果，分别记录物理设备、组件或构建验证。旧 RustDesk 项目可恢复归档。Mac 和 iPad 常规远控沿用上游；本批定制控制端限定为 Android。
